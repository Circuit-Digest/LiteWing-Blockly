# LiteWing Blockly

LiteWing Blockly is the visual block-based programming environment for the LiteWing drone. It enables users to program autonomous drone flights using intuitive drag-and-drop blocks while simultaneously generating clean, real-time Python code compatible with the official `litewing` library.

---

## Official Documentation & Wiki

For comprehensive guides, step-by-step connection instructions, flight safety rules, troubleshooting, and the complete block reference manual, visit the official wiki:

**[LiteWing Blockly Wiki Page](https://circuitdigest.com/wiki/litewing-blockly-wiki-page/)**

---

## Release Package

This distribution package provides the pre-built standalone Windows application:

- `LiteWingBlockly.exe`: Self-contained Windows desktop application. No manual installation of Python, Node.js, or external build dependencies is required.

---

## System Requirements

- Operating System: Windows 10 or Windows 11 (64-bit)
- Connectivity: Built-in Wi-Fi adapter to connect to the LiteWing drone access point
- Hardware: LiteWing Drone with Drone Positioning Module installed
- Firmware: LiteWing firmware v3.0.0 or later
